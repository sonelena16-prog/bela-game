Для учителя

Подключение результатов

Игра готова к подключению. Реальная отправка требует вашей закрытой Google Таблицы и опубликованного обработчика Apps Script. Пока адрес обработчика не задан, сайт не сообщает об успешной отправке.

Скачать полный комплект для GitHub ↓

1. Подготовьте таблицу

  1. Создайте новую Google Таблицу. Не открывайте публичный доступ к её содержимому.
  2. Откройте «Расширения → Apps Script».
  3. Скопируйте содержимое Code.gs в основной файл проекта.
  4. Создайте второй файл скрипта с именем Scoring и вставьте содержимое Scoring.gs.
  5. Сохраните, выберите функцию setup и выполните её под своим аккаунтом. Подтвердите доступ скрипта к вашей таблице. Он создаст лист «Бэла — результаты» с нужными столбцами.

2. Разрешите адрес игры

  1. В Apps Script откройте «Настройки проекта → Свойства скрипта».
  2. Добавьте свойство APP_ORIGINS. Значение — адрес сайта без завершающего слеша и без пути, например: https://имя-игры.chatgpt.site.
  3. Для GitHub Pages добавьте через запятую https://ВАШ-ЛОГИН.github.io. Путь репозитория сюда не включается.

3. Опубликуйте приём работ

  1. Выберите «Развернуть → Новое развертывание → Веб-приложение».
  2. Выполнять от вашего имени; доступ — для всех, кому нужно отправлять работу без Google-аккаунта. Адрес служит только для приёма: содержимое таблицы через него не читается. Возможность такого доступа зависит от настроек вашего Google Workspace.
  3. Скопируйте адрес, заканчивающийся на /exec.
  4. В файле игры dist/config.js задайте его в поле endpoint и опубликуйте сайт заново. Список классов меняется там же. В разделе «Учителю» можно сохранить адрес только на текущем устройстве для предварительной проверки.
  5. Пройдите игру с тестовой анкетой, отправьте результат и проверьте появление строки в таблице. Подтверждение в игре должно содержать номер BELA-…. Повторите отправку этой же работы: новой строки появиться не должно.

В коде используется отправка формы в служебный iframe и подтверждение через postMessage после записи строки. Ошибка сети не считается успешной отправкой. Баллы пересчитываются обработчиком по исходным ответам. Код работы защищает от дублирования при повторном нажатии; новая попытка начинается кнопкой «Новый ученик».

4. Опубликуйте на GitHub Pages

  1. Создайте репозиторий и загрузите исходный проект из подготовленного комплекта, включая папки dist и .github.
  2. В репозитории откройте «Settings → Pages → Build and deployment → Source → GitHub Actions».
  3. Вкладка «Actions»: запустите процесс «Publish Bela game» или отправьте изменение в ветку main.
  4. После успешного выполнения откройте адрес, указанный GitHub Pages.
  5. Добавьте его origin в APP_ORIGINS и повторите тест отправки с опубликованного сайта.

В репозиторий идут код и иллюстрации. Файлы ученических работ, таблица и персональные результаты в него не добавляются.

Если отправка недоступна

Ученик скачивает работу в TXT или JSON. Для импорта JSON обновите Google Таблицу и выберите меню «Бэла → Импортировать JSON работы». Так можно сохранить ответы даже при ограничениях школьной сети.

Как рассчитывается результат

Максимум — 20 баллов. Все 29 ответов проверяются автоматически. Итог: число верных ответов / 29 × 20, с округлением до целого. На каждом этапе показывается количество верных ответов. Развёрнутых письменных заданий нет; отметку и комментарий учитель может внести в отдельные столбцы.

Технические справки: Google Apps Script Web Apps, HTML Service, GitHub Pages.
